
# Safe Steps

A women's safety website written in **C++17** as a single source file, with
**no third-party libraries**. It includes its own small multi-threaded HTTP
server, the full web page, a triage tool, and a PDF generator.

> 

## Features

| Feature | What it does |
|---|---|
| **Fake call** | A realistic incoming call (ringtone and vibration where supported) that gives you a reason to leave a situation. |
| **Alert a trusted contact** | Reads your location only when you tap the button and prepares a ready-to-send message for someone you trust. |
| **What's happening? (triage)** | Describe your situation by choosing an option or typing a few words. You get clear next steps and the right helplines. Covers being followed, online harassment, abuse at home and other concerns. |
| **Personal safety plan** | Fill in a short form and download a styled PDF, generated by hand-written PDF code (`POST /plan`). |
| **Quick Exit** | Switches the screen to an ordinary-looking weather page. |
| **Dark mode** | Follows the device's light or dark setting. |

## Helplines included (India)

| Service | Number |
|---|---|
| Emergency (police, fire, ambulance) | 112 |
| Women Helpline | 181 |
| Women in distress (Police) | 1091 |
| Cyber Crime Helpline | 1930 |

To localise for another country, edit the `LINES` table in
`safe_steps_styled.cpp`.

## Quick start

Requires a C++17 compiler (g++ or clang++) on Linux or macOS. The server uses
POSIX sockets, so Windows needs WSL.

```bash
g++ -std=c++17 -O2 -pthread safe_steps_styled.cpp -o safe_steps
./safe_steps
```

Open <http://127.0.0.1:8080>.

### Options

```bash
./safe_steps 9000          # custom port
./safe_steps 9000 --lan    # listen on all interfaces (e.g. test from your phone on Wi-Fi)
```

Without `--lan`, the server only accepts connections from your own computer.

### Build with CMake

```bash
cmake -S . -B build
cmake --build build
./build/safe_steps
```

## Deployment

The included `Dockerfile` builds the app and runs it on the host's `$PORT`,
listening on `0.0.0.0`. It works on Render, Railway, Fly.io and similar hosts.

```bash
docker build -t safe-steps .
docker run -p 8080:8080 safe-steps
```

**Use HTTPS in production.** Browsers only allow location access on HTTPS (or
localhost), so the "Alert a trusted contact" feature needs it. Most hosts
provide HTTPS automatically.

## Routes

| Method | Path | Description |
|---|---|---|
| GET | `/` | The website |
| POST | `/triage` | Returns steps and helplines for a situation |
| POST | `/plan` | Returns the personal safety plan as a PDF |

## Important note

Safe Steps offers general guidance and is **not a substitute for emergency
services**. If you or someone else is in immediate danger, call your local
emergency number (112 in India).
